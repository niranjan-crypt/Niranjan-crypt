# GITHUB PROFILE & PORTFOLIO — COMPLETE DEVELOPMENT INSTRUCTIONS

## 1. Overall Vision
- Build an exceptionally creative, premium, futuristic personal engineering portfolio.
- Avoid conventional student portfolio templates.
- Prioritize visual storytelling, experimental layouts, immersive animations and smooth interactions.
- The website must feel like a combination of a digital universe, interactive engineering laboratory and premium creative portfolio.
- Maintain a professional, sophisticated and technically credible appearance.
- Do not make the website look like a gaming interface or generic AI-generated landing page.

---

## 2. GitHub README
- Keep the GitHub profile README minimal, clean and professional.
- Do not list every project in the README.
- Do not reproduce the entire portfolio website inside the README.

## 15. Animation & Performance
- Use GSAP for advanced animations.
- Use Framer Motion for interface transitions.
- Use Three.js / React Three Fiber for 3D experiences.
- Use custom shaders only where they add meaningful visual value.
- Optimize animations for desktop and mobile.
- Lazy-load heavy visual elements.
- Respect reduced-motion accessibility settings.
- Avoid unnecessary GPU-intensive effects.
- Ensure smooth scrolling and stable frame rates.
- Prevent layout shifts during animations.
